# DL-Project

A Deep Learning project for Brain Tumor Classification.

## Contents
- **brain_tumor_cnn.py**: Convolutional Neural Network implementation for classifying brain tumors.
- **app.py**: Application entry point or web app for the model.
- **Project1.ipynb**: Jupyter Notebook containing exploratory data analysis, training, and evaluation.
- **dl_utils.py**: Utility functions used throughout the project.
- **brain_tumor_model.h5**: The trained deep learning model (tracked via Git LFS).

## Setup
1. Clone the repository.
2. Install the requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application or notebook to test the model.
